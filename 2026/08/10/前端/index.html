前端

结合羽毛球场地预约系统的前端模板学习 HTML 和 Jinja2 模板语法。

一、HTML 基本结构

1. 一个标准的 HTML 页面

  • <head> — 幕后设置，不显示在页面上
  • <body> — 舞台，所有用户可见的内容

2. HTML 没有变量、没有循环、没有判断

HTML 是标记语言，不是编程语言。它只负责”画结构”——哪里是标题、哪里是段落、哪里是表单。

二、常用标签

1. 文本类

标签 全称 作用 示例
<h1> ~ <h6> Heading 1~6 标题，1 最大 6 最小 <h2>全部场馆</h2>
<p> Paragraph 段落 <p>这是一段文字</p>
<b> Bold 加粗 <b>奥体中心</b>
<br> Break 换行（自闭合） 第一行<br>第二行
<hr> Horizontal Rule 水平分隔线（自闭合） <hr>

2. 链接

  • a — Anchor（锚），超链接标签
  • href — Hypertext Reference（超文本引用），跳转地址

三、属性

属性写在开始标签里，格式：属性名="值"。

属性 全称 常用在哪个标签 作用
href Hypertext Reference <a> 跳转地址
name — <input> 表单字段名（Flask 用 request.form.get("name") 取值）
type — <input> 输入框类型
id Identifier 任何标签 给元素唯一编号，JS 用 getElementById("id") 找到它
required — <input> 必填，浏览器自动校验
value — <input> 默认值
style — 任何标签 行内样式（如 style="color:red;"）

<input> 的 type 常见值

type 值 效果 说明
text 普通文本输入框 默认值，输啥显示啥
password 密码框 输入时显示 ***
date 日期选择器 浏览器自带日历弹窗
hidden 隐藏字段 用户看不见，但随表单一起提交
number 数字输入框 只能输数字，自带加减箭头
email 邮箱输入框 浏览器自动校验 @ 格式
checkbox 复选框 方框打勾，多选
radio 单选按钮 圆形按钮，同一组只能选一个
file 文件选择 弹出文件选择窗口
submit 提交按钮 点击提交表单（<button> 更常用）
四、表单

1. 一个完整的登录表单

2. 各部分的含义

部分 含义
<form method="POST"> 表单开始，method="POST" 告诉浏览器用 POST 方式提交
<input type="hidden" name="action" value="login"> 隐藏字段，用户看不见，但随表单一起提交。Flask 用 request.form.get("action") 拿到 "login"，区分是登录还是注册
name="username" 这个字段的名字。Flask 用 request.form.get("username") 拿到用户输入的值
required 浏览器自动拦截：不填不能提交
<button type="submit"> 提交按钮，点击后表单数据发给服务器

3. type="hidden" — 隐藏字段

  • 用户看不到 — 不画输入框，不占页面空间
  • 但随表单提交 — 点登录时，action=login 一起发给 Flask
  • 用途 — 区分同一个 <form> 是登录还是注册，同一页面可能有多个表单共用一个处理函数
  • 右键”查看源代码”能看到它，但普通用户不会去翻

五、Jinja2 模板语法

HTML 本身没有变量和逻辑。Flask 用 Jinja2 引擎给 HTML 增加了三种标记：

### 1. `{{ }}` — 变量替换 Flask 传 `username="zhangsan"` → 渲染后变成 `

欢迎，zhangsan

`。 ### 2. `{% %}` — 控制逻辑 `{% %}` 里的代码不会出现在最终 HTML 里，只控制"这一段要不要显示"或"这一块循环几次"。 ### 3. 常用辅助函数 | 写法 | 作用 | |------|------| | `{{ url_for('venues') }}` | 根据 Flask 函数名 `venues` 反查 URL `/venues` | | `{{ url_for('courts', venue_id=v['id']) }}` | 带参数生成 URL：`/courts/1` | ### 5. 模板继承 `base.html` 里有一个 `{% block content %}{% endblock %}` 占位，子页面用相同名字的 block 填上内容。
六、JavaScript 事件监听

HTML 里 <script> 标签中的代码是 JavaScript（JS）。JS 负责页面交互——监听用户操作，动态发请求，更新页面。

层 语言 做什么

样式 CSS 化妆——颜色、大小、间距

七、关键术语
术语 全称 含义
HTML HyperText Markup Language 超文本标记语言
标签（tag） — <p> </p> 这类，HTML 的基本单元
属性（attribute） — 标签里的 name="..." href="..."
元素（element） — 一个完整的标签 + 属性 + 内容
自闭合标签 — 没有闭合标签的，如 <br> <hr> <input>
渲染（render） — Flask 把模板里的 {{ }} 替换成真实数据，生成最终 HTML
静态文件 — 不经过模板引擎处理的文件（如 .css .js .png）
