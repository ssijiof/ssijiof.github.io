Erasure Coding-Based Cost-Optimized and Latency-Aware Data Storage in UAV-Enabled Edge Systems

备注：关于纠删码 [12] [13]；关于使用动态 MEC 优于静态 MEC [6]

名词

1. ConvLSTM

CNN + LSTM（长短期记忆），同时捕捉空间和时间信息

2. Erasure Coding — EC(k, m)

原始数据被均分成 k 个 data block（数据块），计算生成 m 个 parity block（校验块，不是原始数据的直接片段，而是数学运算的冗余结果）；共 k + m 个块存储在不同节点上；用户只需从可访问节点中收集任意 k 个块（数据块或校验块均可）即可 reconstruct 原始数据（参考 [14]）

3. 其他关键概念

  • parity block：校验块，通过编码矩阵从数据块计算得出，不包含原始数据本身
  • block placement：编码完成后，k + m 个块分别存放在哪些节点上的放置决策
  • access：恢复数据时从存储节点读取编码块的过程
  • UAV agent：每架 UAV 上的本地存储和计算单元
  • edge agent：地面边缘服务器，算力更强、通信稳定，负责全局编码和放置决策
  • infrastructure-based MEC：边缘服务器部署在固定基础设施（基站/AP），跟 UAV-based MEC 互补
  • D2D communication：UAV 之间不通过基站、直接点对点通信，access 延迟最低
  • cache hit rate：请求的块刚好在邻近节点就有的概率
  • data retrieval delay：从发出请求到完整恢复数据的总耗时
  • non-fully-connected network：UAV 之间不是每对都有直接通信链路，placement 必须考虑网络拓扑

4. FDMA（Frequency Division Multiple Access）

频分多址——将总带宽切分成多个不重叠的子频段，每个用户独占一个子频段同时通信，互不干扰

5. channel gain（信道增益）

接收功率 = 信道增益 × 发射功率。g 衡量信号从发射端到接收端衰减了多少的倒数——g 越大，到达的信号越强。$g \propto 1/d^l$（距离越远 g 越小），NLoS 路径额外乘衰减因子 $a<1$

论文提出的问题
  • UAV 在storage cost（存储成本）和 user data access latency（数据访问延迟）双目标的约束下，使用纠删码策略提供边缘数据存储服务，并将纠删码策略分治为三个子问题：data encoding 、placement subproblem、block access subproblem
问题场景

  • The original data is divided into three data blocks and encoded into two parity blocks. The mobile user, located at the far-right, prioritizes retrieving coding blocks (d3) from the UAV directly covering its location. Coding blocks
    (d2) can be transmitted between adjacent UAVs and delivered to the user. If insufficient blocks are retrieved from the UAVs, the remaining blocks (c2) are transmitted from a remote edge server via UAVs to restore the original data.

    • 救援车辆配备存储资源充当 edge server，协同 UAV 存储编码块，为移动用户提供数据存储服务

  • 本论文考虑 disaster relief 场景，where edge servers based on ground infrastructure（地面设施） are damaged and unable to provide services（没有网络，设备之间通过 D2D 交流）

创新点

  • 使用强化学习解决 joint optimization problems(之前论文使用蚁群算法解决双优化问题，可以进行算法上的对比)

  • 提出 ME-HDRL：Mobility-Enhanced Hierarchical Deep Reinforcement Learning algorithm

  • 目前所看的论文大部分考虑 LOS 而这篇论文综合考虑了 LOS 和 nLOS

基于问题建模

A. System Model

  • 系统组成：1 个 vehicle-based edge server s + U 架悬停 UAV + D 个移动用户
    • UAV 集合：$\mathcal{U} = {1, 2, \dots, U}$
    • 移动用户集合：$\mathcal{D} = {1, 2, \dots, D}$
    • 时间为离散 time slot：$t \in {1, 2, \dots, \tau}$，等长
  • 数据编码：原始数据 f 被均分成 k 个 data block，编码生成 m 个 parity block，共 $N = k + m$ 个 coded block
    • 每个 coded block 大小为 $\frac{\text{size}(f)}{k}$
  • 存储容量：
    • edge server：存储资源充足，可存储全部 N 个 coded block
    • 每架 UAV：至多存储 1 个 coded block [31]（可不可以对存储的数量进行研究）
  • 数据请求：每 time slot，用户 d 以概率 p 发起数据请求，优先从覆盖自己的 UAV 检索 coded block
  • 块传输：coded block 可通过 UAV 间 D2D 传输给用户；UAV 上取不够时从 edge server 通过 UAV 中转取剩余块

B. Mobility Model

  • 所有设备位置是时间 slot t 的函数：

    • edge server s：$l_s(t) = (x_s(t), y_s(t), 0)$，高度为 0
    • UAV u：$l_u(t) = (x_u(t), y_u(t), z_u(t))$，悬停在固定高度
    • mobile user d：$l_d(t) = (x_d(t), y_d(t), 0)$，高度为 0

  • 用户在每 time slot 内沿固定方向移动：

    $$\begin{cases} x_d(t+1) = x_d(t) + dis_d(t) \cdot \cos\theta_d(t), \\[4pt] y_d(t+1) = y_d(t) + dis_d(t) \cdot \sin\theta_d(t), \end{cases}$$
    • $dis_d(t) \in [0, dis_{max}]$：移动距离
    • $\theta_d(t) \in [0, 2\pi)$：移动方向

  • UAV 覆盖模型：

    • $c_{u,d}(t) \in {0, 1}$：整数变量，值为 1 表示用户 d 在 UAV u 的覆盖范围内
    • UAV u 的覆盖向量：$C_u(t) = {c_{u,1}(t), c_{u,2}(t), \dots, c_{u,D}(t)}$

C.Storage Model

  • 放置决策向量：
    • 数据块放置向量：$\mathcal{X} = {x_1, x_2, \dots, x_U}$，其中 $x_i \in {0, 1}$，$x_i=1$ 表示 UAV i 存放 data block
    • 校验块放置向量：$\mathcal{B} = {b_1, b_2, \dots, b_U}$，其中 $b_i \in {0, 1}$，$b_i=1$ 表示 UAV i 存放 parity block
  • 每架 UAV 至多存储 1 个 coded block：$x_i + b_i \in {0, 1}, \forall i \in \mathcal{U}$
  • 总 coded block 数量：$N = \sum_{i=1}^{U} (x_i + b_i)$
  • 存储成本：$Cost = N \cdot \frac{\text{size}(f)}{k}$
  • 关键权衡：k 越大 → 每块越小（存储成本低），但用户需访问至少 k 个块才能解码 → 若覆盖 UAV 不足，需从远端 edge server 取块，增加传输延迟
  • 因此 k 是需要学习的核心参数

D. Communications Model（优化目标 data access latency 相关）

  • 通信类型：A2G（UAV ↔ 用户）、A2A（UAV ↔ UAV）、G2A（edge server ↔ UAV）

  • 多址接入：全部设备使用 FDMA，edge server 总带宽 $\text{W}^{\text{edge}}$，UAV 总带宽 $\text{W}^{\text{UAV}}$

  • 信道模型：

    • A2A（UAV 之间）：以 LoS 路径为主
    • A2G / G2A（UAV ↔ 用户 / edge ↔ UAV）：可能被障碍物遮挡，同时考虑 LoS 和 NLoS 两种路径损耗概率

  • LoS 信道增益（以 UAV ↔ 用户为例）：$g_{u,d}^{\text{LoS}}(t) = \frac{g_0}{(d_{u,d}(t))^l}$

    • NLoS 信道增益：$g_{u,d}^{\text{NLoS}}(t) = \frac{\alpha g_0}{(d_{u,d}(t))^l}$
    • 同理：$g_{s,u}^{\text{LoS}}(t)$、$g_{s,u}^{\text{NLoS}}(t)$ 用于 edge ↔ UAV；$g_{u’,u}^{\text{LoS}}(t)$ 用于 UAV ↔ UAV

  • 距离定义（均为 $L_2$ 范数）：

    • edge ↔ UAV：$d_{s,u}(t) = |\ell_s(t) - \ell_u(t)|_2$
    • UAV ↔ 用户：$d_{u,d}(t) = |\ell_u(t) - \ell_d(t)|_2$
    • UAV ↔ UAV：$d_{u’,u}(t) = |\ell_{u’}(t) - \ell_u(t)|_2$

  • 参数：$\alpha$ = NLoS 衰减因子，$l$ = 路径损耗指数，$g_0$ = 参考距离 $d_0=1m$ 处的信道增益

G2A Communication（edge server ↔ UAV）（其余两个通信方式的建模相似）

  • 复合信道增益（结合 LoS 和 NLoS 效应）：

    $$g_{s,u}(t)=\frac{\hat{P}_{s,u}^{LoS}(t) \cdot g_0}{(d_{s,u}(t))^{l}}$$

  • 有效 LoS 概率（调整了 NLoS 衰减）：

    $$\hat{P}_{s,u}^{\text{LoS}}(t) = P_{s,u}^{\text{LoS}}(t) + a\bigl(1 - P_{s,u}^{\text{LoS}}(t)\bigr)$$

  • 其中 $a<1$ 为 NLoS 链路的衰减因子

  • 基准 LoS 概率（S 形函数）：

    $$P_{s,u}^{\text{LoS}}(t) = \frac{1}{1 + \alpha\exp\bigl(-\beta(\theta_{s,u}(t) - \alpha)\bigr)}$$

  • 仰角 $\theta_{s,u}(t)$：

    $$\theta_{s,u}(t) = \frac{180}{\pi}\arctan\left(\frac{z_u}{\|\|(x_u(t),y_u(t)) - (x_s(t),y_s(t))\|\|_2}\right)$$

  • 带宽分配向量 $\mathcal{H}(t) = {h_1(t), h_2(t), \dots, h_U(t)} $，$h_u(t) \in [0, 1]$ 为分给 UAV u 的频谱份额

  • 传输速率（香农公式）：

    $$r_{s,u}(t) = h_u(t) W^{\text{edge}} \log_2\left(1 + \frac{p_s(t) g_{s,u}(t)}{N_0 h_u(t) W^{\text{edge}}}\right)$$
    • $p_s(t)$ = edge server 发射功率，$N_0$ = 噪声功率谱密度
    • $\alpha$, $\beta$ = 环境参数（urban / rural）

E. System Delay Analysis

  • 数据访问延迟 = 传输延迟 + 解码延迟。随着低复杂度纠删码的发展，解码延迟相对传输延迟可忽略 [30]

  • 用户需要 k 个 coded block 才能解码原始数据，块的来源分三种情况：

  • (1) 直接从覆盖该用户的 UAV u 获取：

    • $w_{d}^{u}(t) \in \{0, 1\}$：指示用户 d 是否从直接覆盖的 UAV u 获取 coded block

  • (2) 从直接覆盖 UAV u 的邻居 UAV u’ 获取：

    • $j_{d}^{u’,u}(t) \in \{0, 1\}$，其中 $\forall u’ \in V_{u}$，$V_u$ 为 u 的邻居节点集

  • (3) 从远端 edge server s 获取，通过直接覆盖 UAV u 转发给用户：

    • $o_{d}^{s,u}(t) = k - \sum_{i\in\mathcal{U}}\sum_{v\in V_{i}} (w_{d}^{i}(t) + j_{d}^{v,i}(t))$
    • 即还需要从 edge server 取的块数 = k - 已经从 UAV 邻居网络拿到的块数
